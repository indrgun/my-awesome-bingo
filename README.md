# 🎉 Soc Ops

### Break the ice. Make connections. Have fun.

**Soc Ops** is an interactive social bingo game designed to energize in-person mixers, team events, and networking sessions. Instead of awkward small talk, players explore the room finding people who match fun prompts like "has a pet" or "speaks more than 2 languages" — then tap to mark off squares and race for BINGO!

## ✨ Why Soc Ops?

🎯 **Purposeful Interaction** — Every conversation has a goal, making it easy to start talking  
🎲 **Random Every Time** — Each game shuffles 24 unique prompts for fresh experiences  
📱 **Mobile-First** — Tap squares on your phone while mingling  
🏆 **Instant Gratification** — Visual feedback and win celebration  
💾 **Auto-Save** — Never lose progress, even if you close the tab

## 🚀 Quick Start

### Play Online
**[🎮 Launch Game →](https://indrgun.github.io/my-awesome-bingo/)**

No installation needed! Open the link on your phone and start playing immediately.

### Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Then open [http://localhost:5173/](http://localhost:5173/) in your browser.

## 🎮 How to Play

1. **Tap "Start New Game"** — Get a randomized 5×5 bingo board
2. **Mingle** — Find people who match each square's question
3. **Mark Squares** — Tap when you find someone who matches
4. **Get BINGO!** — Complete 5 in a row (horizontal, vertical, or diagonal)
5. **Celebrate** 🎊 — Share your win and start a new round!

> 💡 **Pro Tip:** The center square is always FREE!
